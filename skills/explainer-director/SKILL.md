# Explainer director

An explainer is an argument, not a feature tour. The viewer should understand one idea by the end,
and the film should return to the person or situation that made the idea matter.

## Inputs

- The source (article, paper, notes) and any URLs the user supplies.
- The audience, the desired takeaway, the target length and the style pack.
- The claim ledger from the research pass.

## Steps

1. **Find the one thing.** Write the takeaway in the viewer’s words, one sentence. If you cannot,
   the source is not ready.
2. **Choose the spine.** A concrete example worked start to finish, a mechanism revealed one layer at
   a time, a myth turned over, or a before/after. Write the shape in one line.
3. **Build the claim ledger.** Number every claim, quote, number and citation. Mark illustrative
   numbers. Do not derive a claim the source did not make.
4. **Write the brief.** Audience, takeaway, duration, style pack, voice, constraints. One page.
5. **Write the script voice-first.** Target words, not seconds. One idea per scene. A scene is about
   19 spoken words for a 60–90 s explainer; longer films can hold 30–40.
6. **Cut, then cut again.** Remove asides, repeated points and anything that only makes sense if the
   viewer already knows the answer.
7. **Write the beats.** Each beat: ID, start, duration, narration, visual intent, claim IDs,
   archetype. The visual intent is a shape, not a finished layout.
8. **Read it aloud.** If a sentence trips, rewrite it. If a scene has no picture, cut it.

## Completion criteria

- The takeaway is one sentence.
- Every claim on screen has a claim ID.
- The script fits the target duration at the measured voice speed, with deliberate holds.
- Every beat has exactly one idea and one visual shape.
- A human has approved the brief and script before scene code starts.
