# Scene IR is the authoring seam

Free-form scene code makes 60 AI-generated scenes drift; a visual editor would be a second product.
The studio uses a typed scene IR as the narrow waist between the director and the renderer. The IR
encodes archetype, narration, on-screen text, data, citations, duration and transition, and is
validated before any code is generated. The renderer adapter compiles it; free-form code remains an
escape hatch.
