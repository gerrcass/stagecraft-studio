# YouTube package — “What is a harness?”

## Title

**What Is an AI Harness? The Loop That Turns Text Into Action** (59 characters)

## Description

An LLM can write code, but it cannot click a button. This 90-second explainer follows the loop that
turns text into action: tools, a calling syntax, a parser, a result channel and a tool list. It ends
with the kitchen metaphor: an agent is an LLM plus a harness.

Based on Theo t3.gg’s article “What is a harness?” (23 Oct 2026):
https://x.com/theo/status/2113424203345265053
